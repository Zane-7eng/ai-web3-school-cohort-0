## 学习笔记

### Agent 的基本工作方式
Learning Agent 的使命是辅助学员理解课程、规划每日任务、维护学习仓库、生成打卡草稿——不是代替学员完成学习，而是**把学习问题沉淀为可被检索和回看的开源材料**。

### 关键约束
- Prompt 是软约束，不是安全边界——执行、支付、签名需代码校验
- 不要将 token、私钥、密码放入公开仓库
- Learning Agent 负责生成打卡内容，学员手动确认提交
