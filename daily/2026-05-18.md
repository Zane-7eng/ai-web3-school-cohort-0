# 2026-05-18 学习笔记

## 模块：LLM / Prompt / Context

### LLM
- 概率模型，输出"概率上合理的候选"，不是事实
- 能：总结、生成、理解意图。不能：事实校验、权限判断、自动获取外部状态
- 三条原则：模型做推理层不做真相源 / 输出可检查 / 不确定显式降级
- 五概念：Token · Embedding · Transformer · 幻觉 · 多模态

### Prompt
- 你和模型的接口设计，不是咒语
- Instruction 四段式：目标 / 输入 / 禁止 / 输出与失败格式
- Structured Output：JSON schema，代码可查可阻断
- Prompt Injection：攻击者篡改指令 → 标记不可信 → 参数校验 → 人工确认

### Context
- 不是塞信息，是信息治理
- 五层分区：指令层 / 任务层 / 事实层 / 知识层 / 外部层
- Memory 不能替代实时授权
