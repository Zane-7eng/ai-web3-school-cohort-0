# 2026-05-20 学习笔记

## HuggingFace LLM 课程

HuggingFace LLM 课过了第一章，学完第二章，读到第三章微调。

之前学 Handbook 的 11 个模块是概念扫盲，知道 LLM、Prompt、RAG、Agent 这些是什么。这次 HF 课不一样，拆的是底层怎么转的。pipeline 一行代码后面藏了三个步骤，分词器不是随便切字就行，子词分词高频词整用生僻词拆碎，预训练怎么切推理就怎么切不能混用。模型保存就两个文件，蓝图加砖瓦。微调不是换了模型，是身体不变换个头。

踩坑和犯的错：批处理那里裁了跟头，以为 Padding 补了就行，结果不加 Attention Mask 那些补的零会搅乱注意力，同一条句子单独喂和放 batch 喂答案不一样。测验错了两处，GPT 是生成型 Decoder-only 我记成了理解型，padding 用 longest 最省空间我记成了 max_length。第一天装 Hermes 还装错了，npm 上的 hermes 和 pip 的 hermes-agent 完全是两个东西，又踩了 OpenClaw 和 Hermes 抢同一个 Telegram Bot Token 导致间歇性死机。

五轮测验二十题对十八题。
