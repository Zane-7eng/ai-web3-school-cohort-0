# AI 基础 11 模块：做之前先问自己的清单

| 模块 | 做之前先问自己 |
|------|--------------|
| LLM | 它说的我从哪验证？不确定就说不知道。数字/地址要来源 |
| Prompt | 背景 × 任务 × 可用什么 × 输出格式 × 参考 × 不确定怎么处理 × 避免什么 |
| Context | 信息哪来的？事实还是别人说的？有效期？可信度？ |
| RAG | 搜什么范围？标日期。搜不到就说搜不到。旧版本要提醒 |
| Agent | 目标 × 工具 × 哪些自动做 × 哪些必须问我 × 什么时候停 |
| Frameworks | 能不用吗？几步说清楚了吗？以后能换吗？ |
| MCP | 读还是写？写要确认吗？有没有记录？ |
| Vibe Coding | 能改哪些？不能改哪些？改完怎么验证？怎么回退？ |
| Fine-tuning | prompt 试过了吗？数据够 50 条吗？有 eval 吗？ |
| Inference | 慢了怎么办？挂了怎么降级？日志脱敏了吗？ |
| Evaluation | 旧 bug 复现了吗？边界测了吗？恶意输入试了吗？ |
