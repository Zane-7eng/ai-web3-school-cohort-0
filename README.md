## 关于 AI × Web3 School

AI × Web3 School 是一个面向 builders 的开源学习计划，由 LXDAO 与 ETHPanda 共同发起。课程覆盖 AI 基础、Web3 基础、AI × Web3 交叉领域及前沿探索四大板块。
